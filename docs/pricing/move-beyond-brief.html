Brief · Request for quotation · October 2026

Move Beyond Tournament System & Move Score

A multi-sport tournament platform (padel, tennis incl. nations team events, chess and other games sports) with live scoring, venue screens and a companion mobile app. We are requesting quotes for a functionally equivalent build. The full technical requirements document accompanies this brief.

What the system does

AreaKey capabilities
Organisations & rolesMulti-tenant clubs/organisers with strict data isolation; apply/approve; owners, admins, managers, referees, operators; Google/email staff login, referee access codes, invite links, audit log.
Tournament managementEvents and event groups, courts, teams/players (CSV import), groups and round robin, knockout brackets with Plate and placement draws, order of play with rain delay, check-in, clone, Excel export, sponsors and branding.
Tennis team eventsNations ties (S2, S1, Doubles) under the 2026 ITF team regulations: line-ups, order-of-merit checks, ITF ranking, placement lots, short-format singles.

To be quoted as new modules

  • PLANNED Per-court referee access: one code per court, referee sees only that court's matches; QR code on each court's table switches the referee to that court.
  • PLANNED Live video feed of selected courts: camera ingest, low-latency streaming to app and web, live score overlay from the scoring data, replays and highlights, access control, stream health dashboard.
  • PLANNED Professional referee system (international sport-code level): full point-outcome capture, code of conduct and point-penalty scale, shot/changeover/medical timers, challenges, officiating team assignment and certification levels, referee's office dashboard, signed scorecards, official statistics and federation export (ITF/FIP/FIDE).
  • Option: Arabic language and RTL layout.

Reference technology

Next.js + TypeScript web and API (Vercel), PostgreSQL (Supabase), React Native/Expo app with native iOS widgets and Live Activities, shared TypeScript domain library. Integrations: Apple, Google, APNs, Expo push, Apple/Google Wallet, Resend, WhatsApp Cloud API, XPay, Sentry. Equivalent stacks are acceptable.
